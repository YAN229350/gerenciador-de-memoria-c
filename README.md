# Gerenciador de Memória em C

Projeto desenvolvido para praticar conceitos de gerenciamento de memória dinâmica utilizando a linguagem C.

## Funcionalidades

- Alocação dinâmica com `calloc()`
- Liberação de memória com `free()`
- Gerenciamento de ponteiros com `NULL`
- Cadastro de números inteiros
- Visualização dos números armazenados
- Reinicialização dos dados
- Menu interativo no terminal

## Tecnologias utilizadas

- Linguagem C
- Biblioteca padrão do C
- API do Windows

## Objetivo

Compreender na prática o funcionamento dos ponteiros e das funções de alocação e liberação de memória dinâmica.
